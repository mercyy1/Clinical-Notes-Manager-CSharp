# 🩺 Clinical Notes Manager

A Windows Forms application built in C# that allows healthcare professionals to securely create, manage, and update patient clinical notes. Designed for usability and scalability, this project demonstrates practical software development with file handling, form design, and user-centric workflows.

---

## 🚀 Features

- 📝 Add, edit, and delete patient clinical notes  
- 📂 Save and load notes using file I/O operations  
- 🔍 Search and filter functionality  
- 💾 Auto-save and data validation  
- 🧭 Clean and intuitive Windows Forms interface

---

## 🛠️ Built With

- C# (.NET Framework)
- Windows Forms (WinForms)
- Visual Studio
